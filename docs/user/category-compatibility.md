# Category compatibility

This is a finite compatibility matrix, not a claim that every Xtream panel or M3U exporter has been tested. Adapters preserve raw category and stream identities. Core rules clean display names and join live qualities only when metadata agrees. M3U Live, Movie and Series picks remain explicit.

## Sources and fixtures

- [Kodi IPTV Simple documentation](https://github.com/kodi-pvr/pvr.iptvsimple/blob/6d334f6dfa16bbb4c0209ee50bb70f16bccb13bf/README.md#supported-m3u-and-xmltv-elements), revision `6d334f6d`, documents `group-title`, semicolon memberships and persistent `#EXTGRP` directives, including empty and explicit-group resets. `packages/core/test/playlist.test.ts` uses fictional names and reserved `.test` addresses to exercise these rules. No public stream is fetched.
- [Xtream API client types](https://github.com/ektotv/xtream-api/blob/ed075399ec74e273db92c9720e9400068cb98303/src/types.ts), revision `ed075399`, declare string `category_id` and numeric `category_ids` for live, movie and series rows. `apps/desktop/test/provider-categories.test.ts` exercises these through the public adapter with sanitized responses. Missing, empty, repeated and unknown values are defensive contract cases, not evidence of a particular panel.
- `packages/core/test/catalogue.test.ts` and the repository fake provider are synthetic contracts for existing region/display rules, quality grouping and conflict safety. They do not prove broader real-provider coverage. No new country aliases or separators are inferred from them.

## Supported cases

| Input                                                                             | Behavior                                                                                                                                    | Coverage and scope                                                      |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Xtream scalar string/numeric ID or numeric/string membership array                | Keep raw IDs as strings; a nonempty array is authoritative, otherwise use the scalar. Deduplicate memberships and discard empty references. | Adapter live/movie/series contract. Existing shapes, shared conversion. |
| Missing category name                                                             | Keep the existing `Category <id>` fallback.                                                                                                 | Adapter contract.                                                       |
| Missing membership or unknown reference                                           | Channel remains reachable through All; an unknown reference cannot establish variant identity. No guessed category name.                    | Core and library contracts.                                             |
| Duplicate category names with different IDs                                       | Keep raw memberships and IDs; display categories may combine with the existing member list/count rules.                                     | Library contract.                                                       |
| M3U `group-title`, semicolon groups, per-entry `#EXTGRP`                          | Preserve existing memberships and explicit mapping authority.                                                                               | Playlist contracts. Existing support.                                   |
| M3U persistent `#EXTGRP`, before or after `#EXTINF`                               | Apply to following entries; empty directive clears it; explicit `group-title` clears inherited groups.                                      | New documented support, chunked playlist contract.                      |
| Country code/name, multilingual country prefix, flag and existing separator forms | Preserve current display normalization and raw names/IDs. Unknown prefixes stay conservative.                                               | Existing synthetic catalogue contracts, not new provider claims.        |
| Quality-only category beside a topic category                                     | Join an unambiguous quality with that channel; retain every membership.                                                                     | Existing catalogue contract.                                            |
| Conflicting country/language categories or channel prefix                         | Keep streams separate; do not let conflicting memberships bridge other channels.                                                            | Synthetic safety contract.                                              |
| Guide country conflicts with explicit country, or different guide feeds/topics    | Keep streams separate. Shared guide IDs alone never establish identity.                                                                     | Synthetic safety contract.                                              |
| Adult membership among ordinary memberships                                       | Existing adult rules apply to the whole channel/title, including inherited M3U groups. Home remains adult-free.                             | Library, playlist and Home contracts.                                   |

Unsupported raw field shapes are not guessed. Stalker/MAG, automatic title classification and new login protocols are outside this matrix. Real-provider, native-platform and installed-release acceptance require separate evidence.

Guide country suffixes use ISO country codes rather than reseller aliases. `.ar` identifies Argentina and `.af` Afghanistan; category prefixes `AR |` and `AF |` retain their existing Arabic/Africa conventions. Flag-and-guide contract fixtures cover this distinction.
