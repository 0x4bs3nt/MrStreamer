# Home

## Sub-features

16:9 muted live preview with bottom programme/channel/progress controls, Continue watching and next useful episodes, bounded local recommendations, first-page Watchlist, favourite/recent channels, new titles and current category. Persisted order and visibility use stable row IDs; new rows append predictably, unknown future rows survive edits, Reset restores defaults.

## How to get to it

**Home** in the window bar. **Watchlist** after Series in the window bar opens the full list in one step while any user-visible save remains, independently of Home’s row visibility. **Settings > Home** opens one numbered list of every row, including empty ones, with native checkboxes and up/down controls. Tab reaches controls, Space changes visibility, Enter moves a row. Back returns to the previous page; **Reset to defaults** restores order and visibility. Changes save immediately and survive restart.

Default order: Continue watching, Recommendations, Watchlist, Favourites, Recently watched, New movies, New series, Current category. Only nonempty visible rows render. The first visible nonempty channel row in saved order is promoted beside the picture as at most six compact guide-style lines. It appears once; hiding or moving channel rows changes which row is promoted. Remaining channel rows keep their saved positions; Continue watching comes first among the title rows, whose other entries retain saved order. Title rows with one to three entries use small poster or 16:9 still artwork beside text and rounded actions; larger rows retain 2:3 posters or 16:9 stills. Channel art and contained logos keep fixed 16:9 bounds. Explicitly mapped playlists use catalogue titles instead of unreliable added dates. Loading/error/empty catalogue states keep the permanent Home actions reachable. Live-only profiles show Watchlist when visible saved entries remain, without enabling Movies or Series.

The existing category row follows the shared Live TV discovery descriptor: active topic, native category, a list of the viewer's (its name and channels, in its order) or filtered All, with ordinary visibility enforced in main. Unfiltered All stays All, and a deleted list falls back to All. `custom-lists` checks Home's row against Live TV's list. During Favourites/Recent browsing it uses remembered topic/native discovery, then legacy startup choice, then All, without adding another personal row. Its All action opens exactly the shown descriptor and filters. At startup App applies effective remembered discovery before mounting its pages, so Home does not first request an unrelated All catalogue. A failed remembered read falls back to All; a later reread never overwrites an explicit session selection. `renderer/startup-discovery.test.ts` holds the public read and covers cached restoration, genuine All and failure fallback. `live-categories` proves filtered topic list/grid/Home, topic/All/native restart and source removal; renderer browse contracts cover fallback and filter identity.

A pending row save dims and blocks further edits, including after switching Settings tabs or closing and reopening Settings. A Saving label names the pending write. Once it settles, edits use the latest saved preferences. Failed saves leave the saved rows intact, show the error and allow retry; moving a hidden row keeps it hidden after restart.

## Gotchas

Recommendations rank up to three distinct available nonadult seeds from at most 32 recent started plays, including finished films, against loaded catalogues only. They return at most twelve deduplicated titles, up to four per seed. Their reasons name the actual local seed and existing related-title match. Missing/removed seeds and candidates stay out. Provider category/name fallback matches only within its owner; known genres can match across saved owners. Home triggers no recommendation list/details/file request. No history means no personalized row, and incomplete metadata uses existing fallback rules. No content/history leaves the device.

Home's Watchlist query excludes adult entries at its owner, including unavailable adult saves, even when Settings allows them. The full Watchlist keeps that setting. Recommendations and Continue watching also always exclude adult titles. Existing preview ownership and playback controllers are unchanged.

Native audible sound/GPU use, installed packages, actual providers and receiver behavior require coordinator-owned acceptance; Linux Xvfb does not prove those.
