# Settings

Settings opens over playback with Cmd/Ctrl comma or the header button. The rail order is General, Playback, Live TV, Movies and series, Subtitles, Home, Subscriptions, Guides, Updates, Privacy, About. Privacy is directly above About. Both the rail and each section scroll independently. Visited forms stay mounted while Settings is open, preserving drafts, pending/error feedback and scroll positions.

Find a setting searches translated labels, section names and translated synonyms locally in English, Dutch, French, German and Spanish. Enter opens the first result; Down reaches the results. Selecting a result scrolls to and focuses its real control. Clear search recovers from no results. Escape clears a nonempty search, cancels delay editing, closes a nested dialog first, returns licences to About, or closes Settings from outside text editing. Closing Settings clears any unresolved destination and restores the opener's focus when it remains connected, otherwise the playing Title/Watch root or the header Settings button. Ordinary save controls retain keyboard focus while pending and reject repeated writes. Delay Enter commits without blurring; Escape cancels its draft. Keyboard Retry returns to the associated control before its button disappears, or the current rail item or search field when there is no associated control. This includes online-subtitle read recovery. Settings holds the existing next-episode countdown through the UI store; the controller still owns its policy and active countdown snapshot.

## Stable update reminder

From the 0.0.21 client, a direct/Homebrew Stable copy with a fresh available offer and an explicit previous-Stable boundary newer than its installed version receives Update A. Missing/invalid history, current/ahead/one-behind builds, installed Nightly builds, the Nightly channel and managed Store/AUR copies do not. Feed schema 1 remains compatible: `stable.previousStable` is optional and travels with the selected release when a stale feed is merged. GitHub fallback derives the boundary only from known published eligible releases, never patch subtraction.

Prove this path with a custom owned launch of this checkout's built app (using `apps/desktop/test/e2e/app.ts`, as the installed-media harness does), an owned disposable profile, fake provider/TMDB and loopback `MR_STREAMER_UPDATE_FEED`/`MR_STREAMER_UPDATE_API`. The standard `verify:desktop` control helper discards ambient update overrides, so do not use its manual Check now against the public feed. In the custom launch, automatic checks can stay off while Settings > Updates > Check now drives real discovery. Serve a latest Stable and previous-Stable boundary above the installed version, with real-looking fixture notes. Close Settings and inspect Update A, actual versions/notes, Download and Not now. Not now and Escape must return browsing focus and keep Update accessible. Recheck, reload the renderer and change the offer within one process: no repeated dialog. Quit the owned app and relaunch on its owned profile: the reminder can return. A permission response alone does not consume the launch; the mounted popup acknowledges display to the main process.

Check during full Watch and movie/episode playback, including a completed check whose UI answer arrives after playback starts: no dialog until browsing returns. Home's muted preview permits it. Recheck with missing history, one-behind/current/ahead and a failed source: no fresh reminder; the last downloadable offer can remain after failure. Capture the centered dialog and post-dismissal entry, inspect focus, and retain actions, build/process identity and teardown. Service tests protect actual release ordering, stale eligibility, launch reset and inert managed actions; renderer tests protect dismissal/focus, explicit download and deferral. Existing installer progress, ready, cancellation, failure/retry and explicit restart remain covered by updater contracts. A fake feed and development Electron build do not prove installed app-led updates, signatures, native installer behavior or Homebrew/Store/AUR packaging.
